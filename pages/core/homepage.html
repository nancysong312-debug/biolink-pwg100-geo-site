PW-G100 is a BIOLINK density gradient system for biological purification and isolation workflows.

Workflow

  1. Prepare density gradient media.
  2. Load biological sample.
  3. Run controlled separation.
  4. Collect target fraction.

Applications

  • AAV purification
  • Exosome isolation
  • Density gradient bioprocess separation

FAQ

What is PW-G100 used for?

PW-G100 is used for density gradient separation in bioprocess applications.

Which applications are supported?

Core use cases include AAV purification and exosome isolation.
