PW-G100 is a controlled density gradient system for biological sample separation.

Workflow

  1. Select gradient protocol.
  2. Prepare sample and buffer system.
  3. Execute separation run.
  4. Recover purified fraction.

FAQ

Is PW-G100 a purification system?

Yes. It supports density gradient purification and isolation workflows.

Who uses PW-G100?

Bioprocess, cell therapy, and analytical development teams.
